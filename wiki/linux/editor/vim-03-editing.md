모두 Normal 모드에서 사용. 삭제/복사 명령은 motion과 조합 가능 (`d{motion}`, `y{motion}`).

## 1. 삭제

| 키 | 동작 |
|----|------|
| `x` | 커서 문자 삭제 |
| `X` | 커서 앞 문자 삭제 (Backspace) |
| `dd` | 현재 줄 삭제 |
| `{n}dd` | n줄 삭제 |
| `D` | 커서부터 줄 끝까지 삭제 |
| `dw` | 단어 삭제 |
| `d0` | 커서부터 줄 앞까지 삭제 |
| `dG` | 커서부터 파일 끝까지 삭제 |
| `dgg` | 커서부터 파일 시작까지 삭제 |

삭제된 내용은 unnamed 레지스터에 저장 → `p`로 붙여넣기 가능 (잘라내기 효과).

## 2. 복사 (Yank)

| 키 | 동작 |
|----|------|
| `yy` / `Y` | 현재 줄 복사 |
| `{n}yy` | n줄 복사 |
| `yw` | 단어 복사 |
| `y$` | 커서부터 줄 끝 복사 |
| `yG` | 커서부터 파일 끝 복사 |

## 3. 붙여넣기

| 키 | 동작 |
|----|------|
| `p` | 커서 뒤/아래 줄에 붙여넣기 |
| `P` | 커서 앞/위 줄에 붙여넣기 |

## 4. 변경 (Change)

삭제 후 Insert 모드로 진입한다.

| 키 | 동작 |
|----|------|
| `cw` | 단어 변경 |
| `cc` / `S` | 줄 내용 변경 |
| `C` | 커서부터 줄 끝까지 변경 |
| `ci"` | `"` 안쪽 내용 변경 (inner) |
| `ci(` | `(` 안쪽 내용 변경 |
| `ci{` | `{` 안쪽 내용 변경 |
| `ca"` | `"` 포함하여 변경 (around) |
| `ci[` | `[` 안쪽 내용 변경 |

`ci{`, `ci(` 등은 메서드 인자, JSON 값 수정 시 매우 편리.

## 5. Undo / Redo

| 키 | 동작 |
|----|------|
| `u` | 실행 취소 |
| `Ctrl+r` | 다시 실행 |
| `U` | 현재 줄의 모든 변경 취소 |

## 6. 점 명령

`.` — 마지막 변경 명령을 그대로 반복.

```
cwnewword<Esc>   단어를 "newword"로 변경
n                다음 검색 결과로 이동
.                같은 변경 반복
```

여러 곳에 같은 편집을 적용할 때 `/pattern → n → .` 조합이 효율적.

## 7. 들여쓰기

| 키 | 동작 |
|----|------|
| `>>` | 현재 줄 들여쓰기 |
| `<<` | 현재 줄 내어쓰기 |
| `{n}>>` | n줄 들여쓰기 |
| `=G` | 커서부터 파일 끝까지 자동 정렬 |
| `gg=G` | 파일 전체 자동 정렬 |

## 8. 기타

| 키 | 동작 |
|----|------|
| `J` | 아래 줄을 현재 줄 끝에 합치기 |
| `~` | 커서 문자 대소문자 전환 |
| `gUw` | 단어를 대문자로 |
| `guw` | 단어를 소문자로 |
| `gUU` | 줄 전체를 대문자로 |
| `Ctrl+a` | 커서 아래 숫자 +1 |
| `Ctrl+x` | 커서 아래 숫자 -1 |
