## 1. 개념

디렉터리 내 파일과 하위 디렉터리 목록을 출력한다. 기본적으로 현재 디렉터리를 대상으로 하며, 숨김 파일(`.`으로 시작)은 제외된다.

```bash
ls [options] [FILE/DIR...]
```

---

## 2. 주요 옵션

### 2.1. 출력 형식

| 옵션 | 설명 |
|------|------|
| `-l` | 상세 목록 (권한·링크수·소유자·그룹·크기·날짜·이름) |
| `-1` | 한 줄에 하나씩 출력 (파이프 처리 시 유용) |
| `-C` | 다중 열로 출력 (기본값, 터미널) |
| `-m` | 쉼표 구분 목록 |

### 2.2. 숨김 파일

| 옵션 | 설명 |
|------|------|
| `-a` | `.`으로 시작하는 숨김 파일 포함 (`.`, `..` 포함) |
| `-A` | 숨김 파일 포함 (`.`, `..` 제외) |

### 2.3. 크기 표시

| 옵션 | 설명 |
|------|------|
| `-h` | `-l`과 함께 사용. 크기를 사람이 읽기 쉬운 단위로 (1K, 234M, 2G) |
| `-s` | 파일에 할당된 블록 수 표시 |
| `--si` | 1000 기반 단위 사용 (K=1000, M=1000000) |

### 2.4. 정렬

| 옵션 | 설명 |
|------|------|
| `-t` | 수정 시간 기준 정렬 (최신 순) |
| `-S` | 파일 크기 기준 정렬 (큰 것 순) |
| `-r` | 정렬 순서 반전 |
| `-v` | 버전 번호 자연 정렬 (`file2` < `file10`) |
| `-X` | 확장자 기준 정렬 |
| `-U` | 정렬 안 함 (디렉터리 순서 그대로) |

### 2.5. 파일 유형 표시

| 옵션 | 설명 |
|------|------|
| `-F` | 유형 표시자 추가 (`/`=디렉터리, `*`=실행파일, `@`=심볼릭링크, `\|`=FIFO) |
| `-p` | 디렉터리에만 `/` 추가 |

### 2.6. 기타

| 옵션 | 설명 |
|------|------|
| `-R` | 하위 디렉터리 재귀 출력 |
| `-d` | 디렉터리 자체를 항목으로 표시 (내용 아님) |
| `-i` | 각 파일의 inode 번호 출력 |
| `-L` | 심볼릭링크가 가리키는 파일의 정보 표시 |
| `-u` | `-l`과 함께 수정 시간 대신 접근 시간(atime) 표시 |
| `-c` | `-l`과 함께 수정 시간 대신 상태 변경 시간(ctime) 표시 |
| `--color[=WHEN]` | 색상 출력 (`always`/`auto`/`never`) |
| `--full-time` | 날짜/시간 전체 출력 (`-l --time-style=full-iso`와 동일) |

## 3. `-l` 출력 형식

```
drwxr-xr-x  2 alice dev  4096 May 13 10:00 src/
-rw-r--r--  1 alice dev  1234 May 13 09:30 app.jar
lrwxrwxrwx  1 alice dev    10 May 13 08:00 config -> /etc/app
```

| 필드 | 설명 |
|------|------|
| 첫 번째 문자 | 파일 유형 (`-`=일반, `d`=디렉터리, `l`=심볼릭링크, ...) |
| 권한 9자리 | rwx(소유자) rwx(그룹) rwx(기타) |
| 링크 수 | 하드링크 개수 |
| 소유자·그룹 | 파일 소유자와 그룹 |
| 크기 | 바이트 단위 (디렉터리는 메타데이터 크기) |
| 날짜·시간 | 마지막 수정 시간 |
| 이름 | 파일명 (심볼릭링크는 `->` 대상 포함) |

---

## 4. 자주 쓰는 조합

```bash
# 상세 목록 + 숨김 파일 + 사람이 읽기 쉬운 크기
ls -lah

# 최근 수정 파일 순으로 정렬 (배포 후 확인)
ls -lt

# 오래된 파일 먼저 (로그 정리 순서 확인)
ls -ltr

# 큰 파일 순으로 정렬
ls -lhS

# 특정 디렉터리 자체 정보 확인 (내용 아님)
ls -ld /var/log

# inode 번호 확인 (하드링크 비교)
ls -li

# 파이프 처리를 위해 한 줄씩 출력
ls -1 *.log | wc -l
```
