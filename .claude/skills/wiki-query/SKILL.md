# wiki-query

위키에 축적된 지식을 검색해 인라인 인용과 함께 응답한다.

## Steps

1. 위키의 인덱스/카탈로그 페이지(프로젝트 가이드에 위치가 정의돼 있으면 그 경로, 없으면 `index.md`류 파일을 탐색)를 읽고 관련 페이지를 식별한다.
2. 해당 페이지를 읽는다.
3. `[[페이지 이름]]`으로 인라인 인용하여 응답을 생성한다. 프로젝트 가이드(`CLAUDE.md`/`AGENTS.md` 등)에 별도 인용 방식이 정의돼 있으면 그것을 따른다.
4. 위키 내에 관련 응답이 없는 경우 검색 키워드를 제안한다.
