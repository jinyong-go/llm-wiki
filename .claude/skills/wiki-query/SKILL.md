# wiki-query

위키에 축적된 지식을 검색해 인라인 인용과 함께 응답한다.
근거: `AGENTS.md` > `query`.

## Steps

1. `wiki/index.md`를 읽고 관련 페이지를 식별한다.
2. 해당 페이지를 읽는다.
3. `[[페이지 이름]]`으로 인라인 인용하여 응답을 생성한다.
4. 위키 내에 관련 응답이 없는 경우 검색 키워드를 제안한다.
