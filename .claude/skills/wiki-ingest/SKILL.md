# wiki-ingest

진실 공급원(`raw/`)과 인자로 파일 또는 URL 경로를 전달한 경우 해당 파일 또는 URL을 읽어 구조화된 지식으로 통합한다.

## Steps

1. 진실 공급원의 내용을 읽는다.
    - 인자로 디렉터리를 전달한 경우 해당 디렉터리 내 파일도 읽음
    - 인자로 파일을 전달한 경우 해당 파일 읽음
    - 인자로 URL을 전달한 경우 해당 웹 페이지를 읽음
2. 추가 정보가 필요한 경우 웹에서 정보를 조사한다.
3. `wiki/index.md` 확인 후 신규 생성 또는 기존 문서 갱신 여부 확인
4. 조회한 정보를 정리하고 **출처와 함께 초안을 출력**한다.
5. 사용자 허가 시 작성 또는 수정한다.
6. 현재 월의 `logs/YYYY-MM/log.md` 기록(디렉터리 없으면 생성) 및 `wiki/index.md` 갱신

## Rules

- 출처 우선순위는 사용자 지정 진실 공급원 > 웹 공식문서 > 웹 일반문서 (컬럼, 블로그 등)

## Recommendations

- 수사적 표현·과장을 배제하고 기술적 사실에 집중한다.
    - 정확하고 객관적인 어조를 유지하고 기술적 데이터와 정확성에 집중
- 최대한 간결해야 함 
	- 제목과 목차는 서술형 또는 수식어 지양하여 짧은 단어
	- `()`는 축약어나 다른 언어 -> 한글 번역명 또는 한글 -> 다른 언어 번역, 혹은 링크를 위해서만 사용
	- 설명 또는 정보성 서술은 본문에 위치
