# wiki-category

`wiki/`의 파일을 카테고리별로 분류한다.

## Scope

다음 중 하나를 대상으로 수행한다.
- 폴더를 지정한 경우 해당 폴더 하위 파일
- 특정 폴더 하위에서 실행한 경우 그 폴더의 파일들
- 지정이 없으면 `wiki/` 전체 파일

## Steps

1. 대상 폴더의 파일을 읽는다.
2. 유사한 카테고리가 존재하면 폴더 생성 및 관련 파일 이동을 제안한다.
3. 사용자가 승인하면 폴더를 생성하고 파일을 이동한다.

## Note

- 파일 이동 후 영향받는 `[[wiki-links]]`와 `wiki/index.md` 경로를 갱신한다.
- 위키 변경에 해당하므로 현재 월의 `logs/YYYY-MM/log.md`에 이동 내역을 기록한다(디렉터리 없으면 생성).
