모두 Normal 모드에서 사용. 숫자를 앞에 붙이면 반복 (`5j` → 5줄 아래).

## 1. 문자 단위

| 키 | 동작 |
|----|------|
| `h` | 왼쪽 |
| `j` | 아래 |
| `k` | 위 |
| `l` | 오른쪽 |

## 2. 단어 단위

| 키 | 동작 |
|----|------|
| `w` | 다음 단어 시작 (구두점 별도 단어) |
| `W` | 다음 단어 시작 (공백 기준) |
| `b` | 이전 단어 시작 |
| `B` | 이전 단어 시작 (공백 기준) |
| `e` | 현재/다음 단어 끝 |
| `E` | 현재/다음 단어 끝 (공백 기준) |

## 3. 줄 내 이동

| 키 | 동작 |
|----|------|
| `0` | 줄 맨 앞 |
| `^` | 줄 첫 비공백 문자 |
| `$` | 줄 맨 끝 |
| `g_` | 줄 마지막 비공백 문자 |
| `f{c}` | 줄 내 문자 `c`로 이동 (forward) |
| `F{c}` | 줄 내 문자 `c`로 역방향 이동 |
| `t{c}` | 문자 `c` 바로 앞으로 이동 |
| `T{c}` | 문자 `c` 바로 뒤로 역방향 이동 |
| `;` | 마지막 `f`/`t` 반복 |
| `,` | 마지막 `f`/`t` 반대 방향 반복 |

## 4. 줄 이동

| 키 | 동작 |
|----|------|
| `gg` | 파일 첫 줄 |
| `G` | 파일 마지막 줄 |
| `{n}G` / `:{n}` | n번째 줄로 이동 |
| `H` | 화면 상단 줄 |
| `M` | 화면 중간 줄 |
| `L` | 화면 하단 줄 |

## 5. 화면 스크롤

| 키 | 동작 |
|----|------|
| `Ctrl+f` | 한 화면 앞으로 |
| `Ctrl+b` | 한 화면 뒤로 |
| `Ctrl+d` | 반 화면 아래 |
| `Ctrl+u` | 반 화면 위 |
| `Ctrl+e` | 커서 고정, 화면 1줄 아래 스크롤 |
| `Ctrl+y` | 커서 고정, 화면 1줄 위 스크롤 |
| `zz` | 현재 줄을 화면 중앙으로 |
| `zt` | 현재 줄을 화면 상단으로 |
| `zb` | 현재 줄을 화면 하단으로 |

## 6. 블록·괄호 이동

| 키 | 동작 |
|----|------|
| `%` | 매칭 괄호로 이동 (`()`, `[]`, `{}`) |
| `{` | 이전 빈 줄 (문단 위) |
| `}` | 다음 빈 줄 (문단 아래) |

## 7. 마크 (Mark)

특정 위치를 북마크하고 빠르게 되돌아올 때 사용.

```
m{a-z}    현재 위치를 마크 설정
`{a-z}    해당 마크의 정확한 위치로 이동
'{a-z}    해당 마크가 있는 줄로 이동
''        직전 점프 위치로 복귀
```
