## 1. 개념

`top`은 리눅스 시스템의 전반적인 상태와 실행 중인 프로세스를 실시간으로 보여주는 대화형 도구다. `procps-ng` 패키지에 포함되어 기본 설치된다.

`htop`은 `top`과 동일한 역할이지만 ncurses 기반의 컬러 UI, 마우스 조작, 가로/세로 스크롤, 트리 뷰 등을 제공한다. 별도 패키지로 설치해야 한다.

```bash
top [option...]
htop [-dCFhpustvH]
```

## 2. top — 상단 요약 영역 (Summary Area)

```
top - 11:00:01 up 3 days,  2:15,  2 users,  load average: 0.12, 0.08, 0.05
Tasks: 150 total,   1 running, 149 sleeping,   0 stopped,   0 zombie
%Cpu(s):  0.3 us,  0.4 sy,  0.0 ni, 99.2 id,  0.0 wa,  0.0 hi,  0.0 si,  0.0 st
MiB Mem :  64080.5 total,   1662.8 free,  43043.7 used,  19374.0 buff/cache
MiB Swap:   8192.0 total,   4440.0 free,   3752.0 used.  12504.9 avail Mem
```

### 2.1. 1행 — uptime

| 항목 | 설명 |
|------|------|
| 현재 시각 | 시스템 시간 |
| `up N days` | 마지막 부팅 이후 가동 시간 |
| `N users` | 로그인한 사용자 수 |
| `load average` | 최근 1분 / 5분 / 15분 평균 실행 대기 프로세스 수 |

### 2.2. 2행 — Tasks

| 상태 | 설명 |
|------|------|
| `running` | CPU를 사용 중이거나 실행 대기 중 (`R`) |
| `sleeping` | 이벤트/입력 대기 중 (`S`, `I` 등) |
| `stopped` | 작업 제어 시그널로 중단 (`T`, `t`) |
| `zombie` | 실행 종료되었으나 부모 프로세스가 종료 상태를 회수하지 않음 (`Z`) |

### 2.3. 3행 — CPU

| 항목 | 설명 |
|------|------|
| `us` | 사용자 공간 프로세스가 사용한 시간 (un-niced) |
| `sy` | 커널 공간(시스템 콜 등)이 사용한 시간 |
| `ni` | nice 값이 조정된 사용자 프로세스 시간 |
| `id` | CPU 유휴 시간 |
| `wa` | 디스크 I/O 완료 대기 시간 |
| `hi` | 하드웨어 인터럽트 처리 시간 |
| `si` | 소프트웨어 인터럽트 처리 시간 |
| `st` | 하이퍼바이저에게 빼앗긴 시간 (가상 머신 환경) |

### 2.4. 4~5행 — 메모리

| 항목 | 설명 |
|------|------|
| `total` | 전체 물리 메모리 / 스왑 용량 |
| `free` | 커널이 전혀 사용하지 않는 여유 메모리 |
| `used` | `MemTotal - MemAvailable` |
| `buff/cache` | 커널이 성능을 위해 사용 중인 버퍼·캐시 (필요 시 자동 반환) |
| `avail Mem` | 스왑 없이 새 프로세스에 할당 가능한 물리 메모리 추정값 |

## 3. top — 하단 프로세스 목록 (Task Area)

### 3.1. 주요 컬럼

| 컬럼 | 설명 |
|------|------|
| `PID` | 프로세스 ID |
| `USER` | 프로세스 소유자 (유효 사용자명) |
| `PR` | 커널 스케줄링 우선순위. `rt`는 실시간 우선순위 |
| `NI` | nice 값. −20(높은 우선순위) ~ 19(낮은 우선순위) |
| `VIRT` | 가상 메모리 크기 (코드+데이터+공유 라이브러리+스왑 예약 포함 전체) |
| `RES` | 물리 메모리에 실제 상주하는 양 (비스왑) |
| `SHR` | 다른 프로세스와 공유 가능한 메모리 (`RES`의 부분집합) |
| `S` | 프로세스 상태 (`R`/`S`/`D`/`T`/`Z`/`I`) |
| `%CPU` | 마지막 갱신 이후 사용된 CPU 시간 비율 (코어당 최대 100%) |
| `%MEM` | 전체 물리 메모리 대비 `RES` 비율 |
| `TIME+` | 프로세스 시작 후 누적 CPU 사용 시간 (1/100초 단위) |
| `COMMAND` | 실행 명령어 또는 프로그램명 (커널 스레드는 `[이름]` 형식) |

**메모리 관계**: `VIRT ≥ RES ≥ SHR`. RES만 실제 물리 메모리를 차지하며 %MEM의 기준이 된다.

## 4. top 옵션

```bash
top -d 2           # 2초마다 갱신
top -p 1234,5678   # 특정 PID만 모니터링 (최대 20개)
top -u alice       # 유효 사용자가 alice인 프로세스만 표시
top -U alice       # 실제/유효/저장 사용자 중 alice 포함 표시
top -n 5           # 5회 갱신 후 종료
top -b -n 1        # 배치 모드로 1회 출력 (파일 저장/파이프에 유용)
top -H             # 프로세스 대신 스레드 단위로 표시
top -i             # idle 상태 프로세스 숨김 토글
top -o %MEM        # %MEM 기준 정렬로 시작
top -1             # CPU를 코어별로 각각 표시
```

## 5. top 조작키

### 5.1. 정렬

| 키 | 설명 |
|----|------|
| `P` | CPU 사용률(%CPU) 순 정렬 |
| `M` | 메모리 사용률(%MEM) 순 정렬 |
| `T` | 누적 CPU 시간(TIME+) 순 정렬 |
| `N` | PID 순 정렬 |
| `R` | 정렬 순서 반전 |
| `f` | 필드 관리 화면 (컬럼 추가/제거/정렬 기준 설정) |

### 5.2. 표시 제어

| 키 | 설명 |
|----|------|
| `1` | CPU 전체 합산 ↔ 코어별 개별 표시 토글 |
| `H` | 프로세스 단위 ↔ 스레드 단위 표시 토글 |
| `V` | 프로세스 트리(forest view) 토글 |
| `i` | idle 프로세스 숨김 토글 |
| `c` | 명령어 이름 ↔ 전체 경로·인자 토글 |
| `z` | 컬러 모드 토글 |
| `B` | bold 강조 토글 |
| `l` | uptime 행 토글 |
| `t` | Tasks/CPU 행 표시 방식 순환 (텍스트→바 그래프 등) |
| `m` | 메모리 행 표시 방식 순환 |

### 5.3. 프로세스 제어

| 키 | 설명 |
|----|------|
| `k` | 프로세스에 시그널 전송 (PID 입력 후 시그널 번호 입력) |
| `r` | 프로세스 nice 값 변경 (renice) |
| `u` / `U` | 특정 사용자의 프로세스만 필터링 |

### 5.4. 기타

| 키 | 설명 |
|----|------|
| `d` / `s` | 갱신 주기(초) 변경 |
| `W` | 현재 설정을 `~/.toprc`에 저장 |
| `=` | 모든 필터·제한 해제 |
| `h` / `?` | 도움말 |
| `q` | 종료 |

## 6. htop 옵션

```bash
htop -d 20           # 2초(20/10)마다 갱신
htop -u alice        # alice 사용자의 프로세스만 표시
htop -p 1234,5678    # 특정 PID만 표시
htop -C              # 흑백(모노크롬) 모드
htop -t              # 트리 뷰로 시작
htop -s %CPU         # %CPU 기준 정렬로 시작
htop -H 5            # 새/종료 프로세스를 0.5초 하이라이트
htop -F "nginx|php"  # 명령어에 nginx 또는 php가 포함된 프로세스만 표시
```

> `-d` 값은 1/10초 단위. `-d 20`은 2초 간격.

## 7. htop 조작키

### 7.1. 펑션 키

| 키 | 단축키 | 설명 |
|----|--------|------|
| F1 | `h`, `?` | 도움말 |
| F2 | `S` | 설정 화면 (미터 구성, 색상, 컬럼) |
| F3 | `/` | 명령어 이름 검색 (F3으로 다음 일치 이동) |
| F4 | `\` | 프로세스 필터링 (명령어 이름 기준) |
| F5 | `t` | 트리 뷰 토글 |
| F6 | `<`, `>` | 정렬 기준 선택 |
| F7 | `]` | 선택한 프로세스 nice 값 감소 (우선순위 상승, root 전용) |
| F8 | `[` | 선택한 프로세스 nice 값 증가 (우선순위 하락) |
| F9 | `k` | 선택한 프로세스에 시그널 전송 |
| F10 | `q` | 종료 |

### 7.2. 표시 제어

| 키 | 설명 |
|----|------|
| `H` | 사용자 스레드 표시 여부 토글 |
| `K` | 커널 스레드 표시 여부 토글 |
| `I` | 정렬 순서 반전 |
| `P` / `M` / `T` | CPU% / MEM% / TIME 기준 정렬 |
| `u` | 특정 사용자의 프로세스만 보기 |
| `F` | 선택한 프로세스 추적 (정렬로 위치가 바뀌어도 따라감) |
| `p` | 실행 파일 전체 경로 표시 토글 |

### 7.3. 프로세스 태그·조작

| 키 | 설명 |
|----|------|
| `Space` | 프로세스 태그/태그 해제 (복수 선택 후 일괄 시그널 전송 가능) |
| `c` | 선택한 프로세스와 자식 프로세스 모두 태그 |
| `U` | 모든 태그 해제 |
| `+` / `-` | 트리 뷰에서 서브트리 펼치기/접기 |
| `*` | PID 1(init) 하위 전체 펼치기/접기 토글 |

## 8. top vs htop 비교

| 항목 | top | htop |
|------|-----|------|
| 기본 설치 | O (procps-ng) | X (별도 설치) |
| UI | 텍스트, 단색 | ncurses, 컬러 |
| 마우스 조작 | X | O |
| 가로 스크롤 | X | O |
| 트리 뷰 | O (`V` 키) | O (F5) |
| 프로세스 검색 | X | O (F3) |
| 프로세스 필터 | 제한적 (`u`) | O (F4) |
| 복수 프로세스 선택 | X | O (Space 태그) |
| 배치 모드 출력 | O (`-b`) | 제한적 |
| 설정 저장 | `~/.toprc` | `~/.config/htop/htoprc` |
